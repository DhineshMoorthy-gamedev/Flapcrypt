### Development Commands

    # Default Dev Server
    npm run dev

    # Web / Netlify Dev Mode
    npm run dev:web

    # Desktop / Tauri Dev Mode
    npm run dev:desktop

    # Itch.io Dev Mode
    npm run dev:itch

    # Android Play Store Dev Mode
    npm run dev:playstore
  ──────
  ### Production Build Commands

    # Netlify / Web (output -> dist/web/)
    npm run build:web

    # Desktop / Tauri (output -> dist/desktop/)
    npm run build:desktop

    # Itch.io (output -> dist/itch/)
    npm run build:itch

    # Android Play Store (output -> dist/playstore/)
    npm run build:playstore

    # Standard Production Build (output -> dist/)
    npm run build
  ──────
  ### Packaging & Release Commands

  #### 1. Netlify (Web)

    npm run build:web
    # Publish directory: dist/web

  #### 2. Desktop (Tauri)

    # One-time setup
    npm install -D @tauri-apps/cli
    npx tauri init

    # Run / Build native executable (.exe / .msi)
    npm run build:desktop
    npx tauri build

  #### 3. Itch.io (HTML5 Browser Bundle)

    npm run build:itch
    # Compress dist/itch/* into a .zip file and upload to Itch.io

  #### 4. Android APK / AAB (Google Play Store)

    # One-time setup
    npm install @capacitor/core @capacitor/cli @capacitor/android @capacitor/app @capacitor/status-bar @capacitor/haptics
    npx cap init FlapCrypt com.flapcrypt.app --web-dir dist/playstore
    npx cap add android

    # Build & Sync
    npm run build:playstore
    npx cap sync android

    # Open Android Studio to build signed APK / AAB
    npx cap open android
